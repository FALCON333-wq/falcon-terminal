Running in the background (honest limits)

This is a web app. When the screen is off or you switch apps, Android and iOS pause it: no scans, no stop checks, no notifications. That is an operating-system rule; a web page cannot get around it.

What the app does instead: the moment you open it again, it downloads the 1-minute (or 15-minute/1-hour for long gaps) mark-price candles for the time it was asleep and closes any position whose stop was crossed, at the stop price (or worse, if price jumped past it). Those exits are labelled RECONSTRUCTED. Funding is charged up to that exit time. Daily-signal flips are only acted on at the current price when you reopen the app.

"Keep screen awake" stops the phone from sleeping while the app is on screen; it drains battery. For true 24/7 paper trading, run the Python backend on an always-on device (see README: Termux or a small server).

Voice: open Falcon

Phrase: (any phrase you like)

This phrase opens Falcon in the Grok Bot app, not this dashboard. Set it up once in your phone's assistant:

  • Android, Google Assistant: Google Home app → Automations → + → Personal routine (or Assistant settings → Routines → New) → Add starter → "When I say to Google Assistant" → type Open Falcon terminal → Add action → "Try adding your own" → type open Grok Bot (or pick an "Open app" action if your version lists one) → Save.
  • Samsung, Bixby: open Bixby → ⋮ menu → Quick commands → + → "What you say to Bixby": Open Falcon terminal → Add a command → "Type a command": open Grok Bot → Save. Say "Hi Bixby, …".
  • iPhone, Siri: Shortcuts app → + → Add Action → "Open App" → choose Grok Bot → rename the shortcut to Open Falcon terminal. Say "Hey Siri, Open Falcon terminal" (Siri runs shortcuts by their name).

Last step is manual: in Grok Bot, tap Falcon, then tap the call button. As far as we know there is no link that starts a Falcon voice call in one step.

Optional second phrase, e.g. "Open quant terminal", can open this page: (Google/Bixby: open website or the installed app; Siri: "Open URLs" action).

Menu names change between phone and app versions; full steps and what could not be verified are in VOICE_ACTIVATION.md.
